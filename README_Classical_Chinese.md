# 極簡畫板

此乃**無依無賴、獨成一篇**之網頁畫板也。雙擊 `index.html`，即於瀏覽器中可用，無須安裝、無須聯網、無須構建。

其風尚素白簡約，具諸般筆具、圖層、圖文之屬可編，畫幅可自定，且能多式輸出。

---

## 速用之法

| 法 | 為 |
| - | - |
| 獨篇 | 逕雙擊 `index.html`，以今之瀏覽器開之 |
| 壓卷 | 解 `極簡畫板.zip`，啟其中之 `index.html` |

> 須今之瀏覽器如 Chrome / Edge / Firefox / Safari 者（必能 Canvas 2D 而後可）。

---

## 功能

### 筆具

* **擇取 / 移徙**：選圖文之屬，可移、可縮、可轉
* **羽筆**、**柔毫**、**鉛筆**、**橡皮**
* **直線**、**方廓**、**圓**、**矢**
* **文字**

### 圖層

* 立 / 刪圖層，顯 / 隱
* 拖曳以易其序
* 圖層縮影，隨時而現
* 雙擊層名可改之
* 層內圖文，以籤列之，點而取之

### 圖文之屬（矢量，別於像素）

* 文字為獨立之體：可**移**、可**縮**、可**易色**、可**轉**，雙擊更之
* 入圖：點工具之鈕、曳文件於幅上、或右擊「入圖」
* 體既選，現控點，四隅四邊以縮，頂珠以轉

### 畫幅

* **自定其幅**，備常式：800×600、1024×768、1280×720、1920×1080、1080×1080、A4、A3、手機豎
* **自定其色**（素白、任意之色、透明棋格皆可）
* 輪轉以縮，空格 / 中鍵曳以移，雙擊空處以復其視
* 底現縮之率

### 輸出

* PNG（透 / 白 / 今色之底）
* JPEG（白底）
* WebP（透）
* 複以入剪

### 其他

* **悔 / 復**（至多四十步）
* **右擊之單**：入圖、加字、悔復、立 / 刪 / 清層、適窗、速出
* 淡墨**不相疊而益深**（一筆合成）

## 為用之法

* **入圖**：點工具圖鈕、曳圖於幅、或右擊幅上「入圖」。
* **編字**：以字具點幅而書；既存之字，雙擊更之（Enter 以定）。
* **精調其體**：切「擇取 / 移徙」，點體曳控點以縮、曳頂珠以轉；選則工具現「轉」之滑。
* **右擊之單**：右擊幅上以出；既選其體，復現「複」「刪」。

## 技說

* **獨篇之為**：HTML + CSS + 原生 JavaScript，皆內聯，無藉於外。
* **像素與矢量相分**：筆畫繪於層之像素；圖文為矢量之體別藏，可無損而縮、轉。
* **文 / 視相離**：文之幅與視相離，以 `view = {zoom, x, y}` 易而縮移，諸指之位皆反求於文之系。
* **史之影**：悔 / 復，錄層（含像素、矢量之性）之影而存。

```
index.html      # 應用之體（獨篇）
README.md       # 此說
```
