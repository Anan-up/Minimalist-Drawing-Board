頃有**極簡畫板**之網頁應用，基於Canvas而成，具圖層、對象編輯、歷史回溯等專業繪事之要。

---

## 一、總論
- 運行於瀏覽器之輕巧繪圖之具，無須安裝。
- 兼**矢量文字與位圖影像**之混編，行**非破壞性圖層之治**。
- 宜速寫、標註、簡易圖樣之設計，及影像之合成。

---

## 二、核心功能

### 一、器用（繪事編輯之具十種）
| 器 | 用 |
|------|------|
| 選取／移徙 | 擇既成之對象（文字、影像）而操之 |
| 鋼筆、畫筆、鉛筆 | 肆意揮灑；畫筆柔邊（有陰影），鉛筆硬邊 |
| 橡皮 | 拭去像素（用`destination-out`之法，可調其不透明） |
| 直線、矩形、橢圓 | 作幾何之形（按住而曳） |
| 箭 | 端有矢之直線 |
| 文字 | 輕擊畫布置文本框，可即書、易色、改字號 |

### 二、圖層之制
- 許**多層相疊**，每層各藏其像素與對象（文字／影像）。
- 圖層之職：**新建、刪除、更名（雙擊）、顯隱、曳而序之**。
- 每層縮圖見於右畔之板，列其所含文字影像（可點而擇之）。

### 三、對象之編（選取之器下）
- **文字對象**：可移、可縮（控點為之）、可轉（轉柄為之），易其色、字號、不透明。
- **影像對象**：可移、可縮、可轉，調其不透明。
- 既擇，則**屬性之板**自同步，顯色、粗細、不透明、轉角，可即時調之。
- 凡對象之改，皆入**歷史**。

### 四、畫布與視野之控
- **縮放**：轉輪以縮，而光標之位不動。
- **平移**：空格鍵加左鍵曳之，或中鍵曳之。
- **適窗**：雙擊空白處，復縮放平移之初。
- **尺寸預設**：內置多般畫幅（含A3/A4、手機豎屏），亦可自定廣狹（一乃至八千像素）。
- **背景**：純色（取色或預設白）或透明網格。

### 五、歷史（撤／復）
- 錄圖層之構、諸對象之性、畫幅之廣狹、背景之色。
- 至多四十步，捷鍵為**Ctrl+Z / Ctrl+Y**（Mac則Cmd）。

### 六、輸出之能
- 許**PNG（透明／白／當下背景）**、**JPEG**、**WebP**，及**付之剪貼板**（PNG）。
- 輸出則盡含可見之層與對象。

### 七、插圖
- 由工具之鈕，或曳圖而入畫布，自置於當層之中（或所投之處）。
- 許多檔同選。

### 八、右鍵之單
- 供副本／刪除對象、加字、插圖、撤復、圖層之治、輸出之捷。

## 三、技術之巧

### 一、雙緩存與暫筆之合
- 恣意揮灑之時，筆跡先施於**暫時之布（strokeCanvas）**，抬筆乃一併合於層，免疊加而致不透明倍增。
- 橡皮直施於層（`destination-out`），成逐像素之拭。

### 二、對象之系與獨繪
- 文字影像為**獨立之對象**藏於層（不併為像素），可變易、改其性，不為層繪所擾。
- 對象之繪加於層像素之上，存矢量之性。

### 三、坐標之系與縮移
- 凡交互之坐標皆轉為**文檔坐標**（兼DPR、縮放、平移而計），以保其精。
- 畫布所顯之域（`vpW/vpH`）與文檔之幅（`W/H`）相別，成視口裁切與滾動（由平移）之效。

### 四、選取與變換之柄
- 擇對象則現**八縮之柄**與一轉之柄。
- 縮時巧繫其對角，轉角不變（惟改廣狹）。
- 轉時即顯其度，同步於屬性之板。

### 五、歷史快照之制
- 每有所為（畫畢、改對象、變層等），皆存全貌之快照，兼Canvas之base64與對象之參。
- 復時重建Canvas與對象，狀態盡退。

### 六、界面交互之細
- 器具之鈕有懸示（tooltip）。
- 筆之粗細預覽：工具之板靜覽，加以光標相隨之動環（大小隨縮而變）。
- 頂端之具以藥丸分組，觀之簡潔。
- 右畔圖層之表可曳而序之。

### 七、捷鍵之備
- 器具之鍵：`v`（選）、`p`（鋼筆）、`b`（畫筆）、`c`（鉛筆）、`e`（橡皮）、`l`（直線）、`r`（矩形）、`o`（橢圓）、`a`（箭）、`t`（字）、`i`（插圖）。
- `[` ／ `]` 減／增筆之大小。
- `Delete` 刪所擇之對象。
- `Ctrl+0` 復縮放之初。
- 空格暫移。

---

## 四、程式之構與可守
- 用**純JavaScript**（不假外庫），採ES6+之法，條理分明。
- 狀態統於一處（`state`之對象），界面與繪事相分。
- 用SVG內聯之圖，減外求之繁。
- 窗變（resize）則節流以防，優其效。

---

## 五、所宜之事
- 網頁之簡易繪具，可用於線上會議之標註、設計之初稿、教席之演示。
- 亦可為影像標註之具，插圖而後加字或識。
- 以透明背景與多般輸出之故，宜製表情、UI之資等。
