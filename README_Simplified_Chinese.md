# 极简画板

一个**零依赖、单文件**的网页画板。双击 `index.html` 即可在浏览器中使用，无需安装、无需联网、无需构建。

纯白极简风格，支持多种画笔工具、图层、图片与文字对象编辑、画布自定义和多格式导出。

---

## 快速开始

|方式|操作|
|-|-|
|单文件|直接双击 `index.html`，用任意现代浏览器打开|
|解压包|解压 `极简画板.zip`，打开其中的 `index.html`|

> 环境要求：Chrome / Edge / Firefox / Safari 等现代浏览器（需支持 Canvas 2D）。

## 功能一览

### 画笔工具

* **选择 / 移动**：选中文字、图片对象，支持移动、缩放、旋转
* **钢笔**、**画笔（柔边）**、**铅笔**、**橡皮擦**
* **直线**、**矩形**、**椭圆**、**箭头**
* **文字**

### 图层

* 新建 / 删除图层、显示 / 隐藏
* 拖拽调整图层顺序
* 图层缩略图实时预览
* 双击图层名可重命名
* 图层内的文字 / 图片对象以标签形式列出，点击即可选中

### 文字与图片对象（矢量，独立于像素层）

* 文字作为独立对象：可**移动**、**缩放**、**改颜色**、**旋转**、双击重新编辑
* 图片插入：点击工具栏按钮、拖拽文件到画布、或右键「插入图片」
* 对象选中后出现控制点，四角/四边缩放、顶部圆点旋转

### 画布

* **自定义尺寸**，含常用预设：800×600、1024×768、1280×720、1920×1080、1080×1080、A4、A3、手机竖屏
* **自定义背景色**（支持纯白、任意颜色、透明棋盘格）
* 滚轮缩放、空格/中键拖拽平移、双击空白处复位视图
* 底部实时显示缩放比例

### 导出

* PNG（透明背景 / 白色背景 / 当前背景色）
* JPEG（白色背景）
* WebP（透明背景）
* 复制到剪贴板

### 其他

* **撤销 / 重做**（最多 40 步历史）
* **右键菜单**：插入图片、添加文字、撤销重做、新建/删除/清空图层、适应窗口、快速导出
* 低不透明度墨迹**不叠加变深**（整笔一次性合成）

## 操作提示

* **插入图片**：工具栏图片按钮、拖拽图片到画布，或在画布上右键选择「插入图片」。
* **编辑文字**：用文字工具在画布上点击即可输入；对已有文字双击可重新编辑（回车确认）。
* **精确调整对象**：切到「选择 / 移动」工具，点击对象后拖动控制点缩放、拖动顶部圆点旋转；选中时工具栏会出现「旋转」滑块。
* **右键菜单**：在画布区域右键呼出，选中对象时会额外出现「复制」「删除」。

## 技术说明

* **单文件实现**：HTML + CSS + 原生 JavaScript，全部内联，无任何第三方依赖。
* **像素层与矢量对象分离**：画笔笔画绘制到图层像素画布；文字与图片作为矢量对象独立存储，可无损缩放、旋转。
* **文档 / 视口解耦**：文档尺寸与显示视口分离，通过 `view = {zoom, x, y}` 变换实现缩放平移，所有指针坐标都会反向映射回文档坐标系。
* **历史快照**：撤销/重做对图层（含像素数据、矢量对象属性）做快照序列化。
