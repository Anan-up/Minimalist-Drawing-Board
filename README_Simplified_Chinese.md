这是一个功能完整的**极简画板**网页应用，基于 Canvas 构建，具备图层、对象编辑、历史记录等专业绘图工具的核心能力。

---

## 一、整体定位
- 在浏览器中运行的轻量级绘图/设计工具，无需安装。
- 支持**矢量文字与位图图像混合编辑**，并采用**非破坏性图层管理**。
- 适合快速草图、标注、简单图形设计，以及图片合成。

---

## 二、核心功能模块

### 1. 工具集（10种绘图/编辑工具）
| 工具 | 功能 |
|------|------|
| 选择/移动 | 选中并操控已有对象（文字、图片） |
| 钢笔、画笔、铅笔 | 自由绘制，画笔带柔边效果（阴影），铅笔硬边 |
| 橡皮擦 | 擦除像素（使用 `destination-out` 合成模式，支持不透明度） |
| 直线、矩形、椭圆 | 绘制几何形状（按住拖动） |
| 箭头 | 带箭头端点的直线 |
| 文字 | 单击画布放置文本框，支持即时输入、改色、改字号 |

### 2. 图层系统
- 支持**多层叠加**，每层独立存储像素和对象（文字/图片）。
- 图层操作：**新建、删除、重命名（双击）、显示/隐藏、拖拽排序**。
- 每个图层缩略图在右侧面板展示，并列出其包含的文字和图片对象（可点击选中）。

### 3. 对象编辑（选择工具下）
- **文字对象**：可移动、缩放（通过控制点）、旋转（通过旋转手柄）、修改颜色、字号、不透明度。
- **图片对象**：可移动、缩放、旋转、调整不透明度。
- 选中后，**属性面板**自动同步显示颜色、粗细、不透明度、旋转角度，并支持实时调节。
- 所有对象修改均纳入**历史记录**。

### 4. 画布与视图控制
- **缩放**：滚轮缩放，保持光标位置不变。
- **平移**：空格键 + 左键拖动，或中键拖动。
- **适应窗口**：双击画布空白区域复位缩放/平移。
- **尺寸预设**：内置多种画布尺寸（含 A3/A4、手机竖屏），也可自定义宽高（1~8000px）。
- **背景**：支持纯色（拾色器或预设白色）或透明网格背景。

### 5. 历史记录（撤销/重做）
- 记录图层结构、所有对象属性、画布尺寸、背景颜色。
- 最大 40 步，快捷键 **Ctrl+Z / Ctrl+Y**（Mac 对应 Cmd）。

### 6. 导出功能
- 支持 **PNG（透明/白色/当前背景）**、**JPEG**、**WebP**，以及**复制到剪贴板**（PNG）。
- 导出时包含所有可见图层和对象。

### 7. 图片插入
- 通过工具栏按钮或拖拽图片到画布，自动插入到当前图层中心（或拖放位置）。
- 支持多文件选择。

### 8. 右键上下文菜单
- 提供复制/删除对象、添加文字、插入图片、撤销/重做、图层管理、导出快捷操作。

## 三、技术实现亮点

### 1. 双缓存与临时笔画合成
- 自由绘制（笔触类）时，笔画先画在**临时画布（strokeCanvas）**上，抬笔时一次性合成到图层，避免叠加导致不透明度倍增。
- 橡皮擦直接操作图层（`destination-out`），实现像素级擦除。

### 2. 对象系统与独立绘制
- 文字和图片作为**独立对象**存储于图层（不合并为像素），支持变换、修改属性，且不受图层绘制影响。
- 对象渲染叠加在图层像素之上，保持矢量特性。

### 3. 坐标系统与缩放/平移
- 所有交互坐标均转换为**文档坐标**（考虑 DPR、缩放和平移），保证操作精确。
- 画布显示区域（`vpW/vpH`）与文档尺寸（`W/H`）分离，实现视口裁剪与滚动效果（通过平移）。

### 4. 选择与变换手柄
- 选中对象时显示**8个缩放手柄**和1个旋转手柄。
- 缩放时智能锚定对角，保持旋转角度不变（仅改变宽高）。
- 旋转时实时显示角度值，并同步到属性面板滑块。

### 5. 历史快照机制
- 每次操作（绘制结束、对象修改、图层变更等）均保存完整快照，包括 Canvas 的 base64 数据和对象参数。
- 恢复时重建 Canvas 和对象，保证状态完全回退。

### 6. UI 交互细节
- 工具按钮带有悬浮提示（tooltip）。
- 画笔粗细预览：工具栏静态预览 + 光标跟随动态圆环（尺寸随缩放变化）。
- 顶部工具栏采用药丸分组，视觉简洁。
- 右侧面板图层列表支持拖拽排序。

### 7. 快捷键支持
- 工具快捷键：`v`（选择）、`p`（钢笔）、`b`（画笔）、`c`（铅笔）、`e`（橡皮）、`l`（直线）、`r`（矩形）、`o`（椭圆）、`a`（箭头）、`t`（文字）、`i`（插入图片）。
- `[` / `]` 减小/增大笔刷尺寸。
- `Delete` 删除选中对象。
- `Ctrl+0` 重置缩放。
- 空格临时平移。

## 四、代码结构与可维护性
- 采用 **纯 JavaScript**（无第三方库），使用 ES6+ 语法，组织清晰。
- 状态集中管理（`state` 对象），UI 和渲染分离。
- 使用 SVG 内联图标，减少外部请求。
- 防抖处理窗口 resize，优化性能。

---

## 五、适用场景
- 网页版简易绘图工具，可用于线上会议标注、设计初稿、教学演示。
- 也可作为图片标注工具，插入图片后添加文字或标记。
- 由于支持透明背景和多种导出格式，适合制作表情包、UI 素材等。
